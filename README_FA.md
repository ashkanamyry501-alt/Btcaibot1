# ربات گزارش تحلیل ارز دیجیتال تلگرام

این پروژه هر ساعت یک‌بار (حدود دقیقه ۷ هر ساعت به وقت UTC) با GitHub Actions گزارش بازار می‌فرستد.
زمان‌بندی ممکن است به دلیل صف GitHub کمی دیرتر اجرا شود. این ربات فقط تحلیل می‌فرستد و معامله باز نمی‌کند.

## راه‌اندازی
1. فایل‌های این پروژه را در یک مخزن GitHub قرار بده.
2. در مخزن به Settings → Secrets and variables → Actions → New repository secret برو.
3. دو Secret بساز:
   - `TELEGRAM_BOT_TOKEN` = توکن ربات تلگرام (آن را در فایل کد قرار نده)
   - `TELEGRAM_CHAT_ID` = شناسه چت تلگرام
4. به Actions برو و اگر گزینه فعال‌سازی workflow را دیدی، آن را فعال کن.
5. از بخش Actions، workflow با نام `Crypto report every hour` را باز کن و از Run workflow یک اجرای آزمایشی انجام بده.
6. نتیجه را در تلگرام بررسی کن.

## امنیت و محدودیت‌ها
- توکن ربات را در کد، مخزن عمومی، پیام یا تصویر منتشر نکن.
- مخزن عمومی به معنی عمومی بودن کد است؛ Secretها در کد نمایش داده نمی‌شوند.
- GitHub زمان‌بندی را تضمین دقیقه‌به‌دقیقه نمی‌کند و ممکن است اجرا با تأخیر باشد.
- داده‌ها از API عمومی Kraken دریافت می‌شوند؛ گاهی API یا نماد بازار ممکن است خطا بدهد.
- این تحلیل بک‌تست نشده و سیگنال سود را تضمین نمی‌کند. قبل از پول واقعی، با حساب آزمایشی بررسی کن.
- استفاده از مخزن عمومی با runner استاندارد رایگان است طبق مستندات GitHub؛ شرایط و سهمیه‌ها ممکن است تغییر کند.
